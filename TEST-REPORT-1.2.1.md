# UniReader 1.2.1 — исправление клавиатуры

Причина: обработчик касания в режиме редактирования вызывал ввод только для Calc и PDF. Для Writer, Impress и Draw он передавал координаты движку без открытия поля ввода. Кнопка «Текст» работала, но требовалось отдельное действие.

## Исправление

- Касание текста в Word/Writer, Impress/PowerPoint и Draw автоматически открывает поле и клавиатуру. Для надписей сразу активируется текст объекта. Двойное касание в Writer сохраняет выбор слова.
- Открытие ожидает готовности окна и фокуса. Ограниченные повторные запросы прекращаются после успешного вызова или закрытия окна.
- Одновременно открывается только одно окно текста; устаревшие запросы при смене документа/режима игнорируются. Закрытие документа закрывает его окно ввода.
- Такой же вызов применяется в поиске и вводе адреса ячейки. Таблицы сохраняют встроенную строку формулы, PDF — свой редактор строк/надписей.

## Проверка

Эмулятор Android 14 API 34 x86_64, 1080×2400, density 420, emulator-5554. Физический ARM64-телефон не использовался.

21 сценарий: DOCX, ODT, PPTX, ODP, ODG, RTF, TXT, FODT, DOTX, DOCM без макросов, POTX, PPSX, FODP, классические DOC/PPT, SVG с текстом, XLSX, ODS, CSV, TSV, PDF с текстовым слоем.

Для каждого файла: открыть → редактировать → один раз коснуться текста/ячейки → проверить mInputShown=true до касания поля → ввести маркер → применить → прочитать сохранённый ODF/PDF-черновик и проверить маркер независимым ZIP/XML или pypdf-парсером. Координаты получены из UI-дерева, размеров/масштаба документа и известных геометрических данных тестовых файлов. Результаты и снимки в qa/v1.2.1/.

Android lint: 0 ошибок. ARM64/x86_64 release собраны; подписи v2/v3 и zipalign -P 16 проверены. Версия 1.2.1, versionCode 4, прежние applicationId и подпись сохранены.

Дополнительные проверки поведения и подписанной сборки записаны в supplementary-results.txt. Основные проверки PDF, экспорта и масштабирования 1.2 сохранены в TEST-REPORT-1.2.md.

Ограничение: это автоматический вызов редактора существующего текстового слоя, не OCR. В сканированном PDF для ввода используется «Добавить надпись». Растровая картинка сама по себе не становится редактируемым текстом. Тестовый HTML-файл не открылся в текущей сборке LibreOfficeKit (loadComponentFromURL returned an empty reference); это ограничение фильтра открытия, не сбой клавиатуры. Этот файл не включён в число пройденных сценариев, HTML-фильтр этим обновлением не изменяется.
